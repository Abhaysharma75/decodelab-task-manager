# decodelab-task-manager
A modern and responsive Task Management Web Application built with HTML5, CSS3, and JavaScript. Features include task priorities, search functionality, task completion tracking, Local Storage, Clear All, Dark Mode, and a clean mobile-friendly interface. 🚀
